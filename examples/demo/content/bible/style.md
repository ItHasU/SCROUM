# Direction artistique

- **Île (`ile`)** : aquarelle, bleus délavés, ocres. Préfixe de prompt :
  « aquarelle, île bretonne, lumière d'orage ».
- **Songe (`songe`)** : pixel art 16 couleurs, violets et turquoises.
  Préfixe : « pixel art, grotte onirique, bioluminescence ».
- Négatif commun : « texte, filigrane, logo ».
